# Bravo Healthcare Website

Professional website for Bravo Healthcare, representing Bravo Home Health and Bravo Residential (coming soon).

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React
- Framer Motion
- React Hook Form + Zod

## Source of truth

- `reference/bravo-healthcare-content.md`
- `reference/source-documents/`
- `.cursor/rules/`

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Official logo: `public/images/logo/bravo-healthcare-logo.png`

Do not invent phone numbers, fax numbers, insurance lists, testimonials, or statistics.
